# Тесты главной страницы на vitest + RTL

Главная статична, ценность — в текстах из глоссария и навигации на `/booking`; решили покрыть Главную страницу и роутинг `App` юнит-тестами на `vitest + Testing Library + jsdom` и гонять их через `make test` и CI — чтобы регрессии текстов и роутера ловились без браузера.

## Considered Options

- Playwright e2e — overkill для статики, требует браузер в CI.
- vitest без RTL — неудобно проверять роли, тексты и клики по ссылкам.
- Не трогать `make test` / CI — тесты не гонялись бы в `make ci`.

## Consequences

- Нужны `devDependencies` фронта и `vitest.config` с `jsdom`; CI-джоба `test` ставит зависимости фронта.
- Тексты возможностей заморожены тестами — правки копипасты требуют обновления тестов.
