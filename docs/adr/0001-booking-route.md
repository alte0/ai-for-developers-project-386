# Отдельный роут /booking для записи

Главная рассказывает про сервис (о сервисе, возможности) и ведёт на отдельную страницу записи `/booking`, а не на модалку, якорь или внешний сервис — чтобы сценарий Владелец публикует слоты → Гость занимает слот жил внутри приложения и расширялся формой и админкой.

## Considered Options

- Модалка на главной — быстро, но не даёт ссылки и ломается на шаге подтверждения.
- Якорь `#booking` — тот же документ, не масштабируется под выбор типа события и слота.
- Внешний сервис — уводит сценарий и данные наружу.

## Consequences

- Понадобится клиентский роутер; `/` остаётся лендингом, `/booking` — точкой входа в сценарий Записи.
